# 绩点计划 / GPA Planner

一个在浏览器本地运行的累计绩点目标计算器。输入当前累计绩点、已修学分、本学期课程和目标绩点，生成一套可以达标的各科成绩方案。

这是公开展示和下载版本，所有内置成绩与课程均为虚构。仓库中的代码不附带 MIT、GPL 等开源授权；进一步使用范围见 [RIGHTS.md](RIGHTS.md)。第三方组件继续适用各自许可证。

## 功能

- 支持学校自定义百分制线性规则、分段规则及等级绩点映射。
- 支持课程手动填写、Excel 导入预览和导入模板下载。
- 百分制和等级课程的预计成绩都可留空，自动分配建议分数或等级；填写成绩后固定该课程。
- 按 01–04 步骤操作，累计绩点结果与各科成绩方案统一显示在第 4 部分。
- 目标不可达时显示最高可达绩点，不生成超过满分的成绩。
- 使用精确有理数判断达标条件，绩点显示保留四位小数。
- 支持手机、桌面和离线使用，成绩数据不会发送到服务器。

## 使用

解压项目，直接用现代浏览器打开 `dist/index.html`，无需安装依赖。

也可以使用 Node.js 18 或更新版本启动本地服务：

```sh
node server.cjs
```

浏览器访问 http://127.0.0.1:4173。页面没有持久存储，刷新后会清空当前输入。

## 计算方式

历史“学分×绩点”合计为 P，已修学分为 C，新增学分为 N，目标绩点为 T，本学期需要贡献的学分绩点为 `T × (C + N) − P`。

如果没有精确的 P，使用“当前累计绩点×已修学分”估算。学校规则必须与历史成绩采用的规则一致，已经计入当前绩点的课程不要重复填写。

对于留空课程，先按共同绩点上限生成均衡方案，再降低仍可达标的成绩。方案不是每科唯一的最低要求；修改某科固定成绩可以重新分配其余课程。

## 示例与测试

“载入虚构示例”使用累计绩点 3.8、40 已修学分、152 学分绩点合计，以及 5 门通用虚构课程。示例不来自实际学生成绩，不含姓名、学号、原始成绩截图或 Excel 附件。

```sh
node --test tests/core.test.cjs
```

测试覆盖虚构案例的精确目标边界、固定成绩、等级成绩留空分配、分段规则、异常输入和 Excel 读写。

## 文件

- `dist/index.html`：网页入口。
- `dist/styles.css`：页面样式。
- `dist/app.js`：交互、导入与结果展示。
- `dist/core.js`：精确计算及成绩分配。
- `dist/vendor/`：离线使用的 SheetJS 0.20.3 及其许可证。
- `tests/core.test.cjs`：计算和 Excel 测试。
- `server.cjs`：可选本地静态服务。

## 第三方组件

Excel 处理使用 SheetJS Community Edition 0.20.3，其许可证见 `dist/vendor/LICENSE-SheetJS.txt`。运行本地服务和测试不需要安装第三方依赖。
